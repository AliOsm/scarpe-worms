Burrow Brigade 0.5.7 improves movement response and reduces work during combat.

- Walking, jumping and backflips appear locally while the server confirms the
  movement. **Settings → Responsive movement** is on by default; turn it off
  to compare with the previous behavior. Weapons, damage, terrain and turns
  remain authoritative on the host.
- The Mac app now includes OpenAL Soft using CoreAudio. Its 24 effect voices
  give explosions and character reactions room to finish during busy battles,
  and its two-period 256-frame profile keeps the mixer lead time near 5 ms.
  Windows and Linux also use the larger pool. Source installations using
  Apple's older OpenAL framework retain the 12-voice fallback.
- Damage-label nodes are prepared during quiet frames, reducing the work when
  the first explosion hits several grubs.
- Crater textures use faster lossless PNG encoding. The landscape keeps the
  same pixels and collision mask while its worker finishes updates sooner.

Existing settings, saved matches and protocol-4 servers remain compatible.
The Mac download supports Apple silicon and macOS 13+. The clients include
their runtimes; no Ruby or Rust installation is needed.

Automated measurements describe client preparation, submitted frames and mixer
output. Physical display latency, audio devices and network conditions vary.
The desktop clients remain preview builds: the Mac app is ad-hoc signed and
unnotarized, and the Windows installer is unsigned.
