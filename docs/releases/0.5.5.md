This is the first downloadable release of Burrow Brigade.

- **Windows and Linux.** The game now runs on Windows 10/11 x64 (installer or
  portable ZIP) and on Linux x86-64 desktops (portable tar.gz), alongside the
  Apple silicon Mac app. Each client bundles Ruby, the native renderer and its
  audio library.
- **Releases.** Every version tag now builds, launches and plays a bot match with
  each client on its own operating system, builds and tests the server image for
  amd64 and ARM64, and only then publishes the downloads with checksums.
- **Logs on every platform.** Timing logs (including `audio.json`) go to
  `%LOCALAPPDATA%\Burrow Brigade\Logs` on Windows and
  `~/.local/state/burrow-brigade/logs` on Linux; macOS keeps
  `~/Library/Logs/Burrow Brigade`.
- **Faster and smoother (0.5.4).** The host no longer stalls for ~60 ms after
  every crater, craters appear ~230 ms sooner, matches start about a second
  faster, and delayed sounds start on time.
- **Grub reactions (0.5.3).** Grubs squeak, call for a medic and say "buh-bye";
  deaths leave a ghost and a gravestone; big hits get comic POW!, BONK! and
  KABOOM! bursts.

Hosts and clients must use protocol 4. Existing settings and unfinished matches remain compatible.
