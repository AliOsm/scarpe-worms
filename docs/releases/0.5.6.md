Burrow Brigade 0.5.6 moves every client and the server to Ruby 4.0.7.

- Source installations require Ruby 4.0 or newer. Ruby 3 support and its CI
  matrix, runtime archives, load-path shims and unused ABI binaries are removed.
- The native renderer and launchers use Rust 1.99.0.
- macOS and Linux bundle Ruby built from checksum-pinned sources, including
  OpenSSL, libffi, libyaml, zlib and the separate Fiddle gem. The macOS app is
  built natively on Apple silicon. Windows bundles official RubyInstaller 4.0.7.
- The server image uses the digest-pinned Ruby 4.0.7 base on amd64 and ARM64.

Existing preferences and saved matches remain compatible. Network protocol 4
is unchanged. Players do not need to install Ruby or Rust for the downloads.
The desktop clients remain preview builds; macOS is ad-hoc signed and
unnotarized, and the Windows installer is unsigned.
